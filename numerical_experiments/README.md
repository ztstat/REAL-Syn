# REAL-Syn Numerical Experiments

Simulation code for **REAL-Syn: Risk-guided Estimation-aware Acceptance for
Learning with Synthetic Data**. This package covers Gaussian linear regression,
logistic regression, acceptance-pattern plots, weighting and resampling
comparisons, and sensitivity analyses. Data are generated by the configured
statistical models; no external dataset or GPU is required.

## Installation

Use Python 3.11 or later. The pinned dependencies have been checked with
Python 3.13.7.

~~~bash
python -m venv .venv
# Activate the environment using the command for your operating system.
python -m pip install -r requirements.txt
python run.py --list
~~~

Run commands from this directory. Paths are resolved within the checkout.
Experiments require NumPy, SciPy and Matplotlib; tests use unittest.

## Layout

~~~text
common/                              Shared OLS, ratio, and output utilities
experiments/
    lowdim_ols/configs/              OLS with d = 1, 2, 5
    highdim_ols/                     Sparse/dense OLS with d = 10, 20
    logistic_regression/             Balanced/imbalanced classification
    acceptance_visualization/       Figure 1 configuration
    acceptance_budget/              Fixed-expected-acceptance alpha sweeps
    weighting_resampling/           Equal-budget SIR and SNIS comparisons
    full_pool_importance_weighting/ Fixed-pool alpha sweep and All-IW
    density_ratio_sensitivity/       Joint-ratio shrinkage
    proposal_mismatch/              Local and stress proposal grids
tests/                               Mathematical and configuration tests
results/                             Generated outputs (not tracked)
experiments.json                     Command-to-configuration registry
run.py                               Unified command-line entry point
~~~

Low-dimensional OLS and Figure 1 share common/ols_pipeline.py.
Each other category has its own pipeline or run module, retaining its
specialized sampling, fitting and aggregation conventions.


## Running Experiments

List all available experiments:

```bash
python run.py --list
```

Run an experiment with its full configuration:

```bash
python run.py ols-d5
```

For a quick functionality check with reduced repetitions:

```bash
python run.py ols-d5 --quick
```

Quick runs are for testing only and do not reproduce the reported Monte Carlo results. Outputs are saved under `results/`.
